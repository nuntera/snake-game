Snake Game - Custom Version.

🎮 About the Game  
The Snake game is a timeless classic where the player controls a snake that grows in length as it eats food. The goal is to eat as much food as possible without colliding with the walls or the snake's own body.

🚀 How to Play  
Controls:  
Use the arrow keys to control the snake's direction.
